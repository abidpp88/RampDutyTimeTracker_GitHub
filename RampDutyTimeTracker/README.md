# Ramp Duty Time Tracker – V1

Android Studio project for the first prototype.

Features:
- Flight number, aircraft type, stand
- One-tap timestamp recording
- On Block / Chocks / GPU / A/C / Step
- BY = Local Baggage
- BT = Transfer Baggage
- Door Closed / Off Block
- Automatic turnaround, BY delivery, and BT delivery durations
- Notes

Next V2 improvements:
- Persistent daily flight history
- Edit/delete flight
- Completed timestamp locking
- Daily summary
- PDF/CSV export
- Delay reason and manpower/equipment modules
